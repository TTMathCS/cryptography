# Start here: secret codes

*Six short lessons for young beginners, about five minutes each, with something to try. No math needed beyond counting. When you finish, the [Book](../book/index.md) takes you further.*

| | Lesson | You will |
|---|---|---|
| 1 | [Why keep secrets?](01-Why-Secrets.md) | see the two jobs of cryptography: hiding and checking |
| 2 | [The Caesar shift](02-Caesar.md) | make a code wheel and send a secret message |
| 3 | [Cracking Caesar](03-Cracking-Caesar.md) | break a code by counting letters |
| 4 | [A code nobody can break](04-One-Time-Pad.md) | use dice to make a perfect secret, and see why it is hard to use |
| 5 | [Locks and keys](05-Locks-and-Keys.md) | send a secret to someone you have never met |
| 6 | [Strong passwords](06-Passwords.md) | roll dice to make a password that is easy to remember and hard to guess |

For teachers: each lesson works on paper, with a pencil, a few dice and a partner.
