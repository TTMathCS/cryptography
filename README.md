# Cryptography

A cryptography course from beginner to expert: the history, the math toolkit,
then every algorithm family that SSH, TLS and PKI rely on, each with its story
(who made it, why, what it fixed, why it was retired, the incidents), how it
works, its standard and its current status.

The course order is the `nav` in `mkdocs.yml`; the lessons that aren't about a
single algorithm are in `docs/learn/`.

Read it at <https://cryptography.akadian.ca/>. The pages live in `docs/`.
